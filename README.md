### FPGA Enigma Machine

The Enigma cipher rebuilt as digital logic in VHDL on a Basys 3 (Artix-7) FPGA, instead of simulated in software. It includes a control FSM, button debouncing, a MOD 26 ALU, rotor stepping and a multiplexed 7-segment display. Team project for *Tecnología de Computadores* at UCM.

**Stack:** VHDL, Vivado

**Links:** [Repository](https://github.com/J-O-Systems/FPGA-Enigma-Machine) · [User manual](https://github.com/J-O-Systems/FPGA-Enigma-Machine/blob/main/Manual_de_instrucciones%20-%20Maquina_Enigma.pdf) · [Project report](https://github.com/J-O-Systems/FPGA-Enigma-Machine/blob/main/Proyecto_enigma.pdf)
